## Current visuals and data

The current visuals are original graphics generated by project code:

- [Crew sprites](src/sprites.js) use Canvas pixel shapes.
- [Colony scenery and creatures](src/render.js) and the [elements laboratory](src/elements-app.js) use Canvas drawing commands.
- The interface uses [CSS](style.css), [laboratory CSS](elements.css), and an inline geometric SVG favicon in [index.html](index.html).

The game runtime bundles no image, font, audio or model files and no third-party libraries. Fonts and Unicode symbols are rendered using the user's installed system fonts; those fonts are not distributed here.

The compressed files in [tests/fixtures](tests/fixtures/) contain game-generated test states. Their accompanying provenance records describe capture methods and source hashes.

## References and external tools

Named games, tools and asset packs in the documentation are design or workflow references. Dwarf Fortress, the Space Station 13/14 family and Unitystation are design references; Pixelorama, LibreSprite and Kenney packs are external tool or asset options. Their code, binaries and assets are not bundled. SPACEFORTRESS is an independent project with no affiliation to those projects.

See [graphics and tools](docs/graphics-and-tools.md) and [station simulation references](docs/station-systems-reference.md) for the research record. Future third-party assets must include their source, license and required notices alongside the imported files.
