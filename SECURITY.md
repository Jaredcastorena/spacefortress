# Security Policy

## Supported versions

SPACEFORTRESS is an early playable project. Security fixes are made on the current default branch; older snapshots and forks are not maintained by this project.

## Reporting a vulnerability

Please do not file a public issue for an unpatched vulnerability.

If private vulnerability reporting is available on the repository's **Security** page, use it. Otherwise, contact the maintainer through a non-public contact method on their Git hosting profile. Include the affected files or feature, reproduction steps, impact, and any suggested fix. Avoid including unrelated personal or system data, credentials, access tokens, private keys, or other secrets.

The maintainer will acknowledge a report when it is seen, assess the impact, and coordinate disclosure after a fix is available. Response and release times depend on the issue and maintainer availability.

## Scope

Reports about the local server, browser save/import handling, or repository tooling are in scope. The server binds to loopback for development and is not intended for untrusted networks or production hosting.
